# FINOVIX - Money Transfer & Exchange Platform

A comprehensive web-based money transfer and currency exchange platform connecting users with registered exchange offices for international transfers.

## Features

### User Features
- **Registration & Login** - Mobile number or email registration with auto-generated account numbers
- **Wallet Dashboard** - View balance, account number, recent transactions
- **International Money Transfer** - Send money to Afghanistan and Pakistan with real-time exchange rates
- **Bank Deposits** - Upload payment receipts and track deposit requests
- **Withdrawals** - Request fund withdrawals with automatic approval workflow
- **Currency Converter** - Real-time exchange rate calculator (USD, EUR, AFN, PKR, IRR)
- **Transaction History** - Download transfer receipts in PDF format

### Exchange Office Features
- Registration and profile management
- Service approval workflow
- Display on platform after admin approval

### Admin Features
- User management and balance adjustments
- Deposit/withdrawal/transfer approval
- Exchange office management
- Automatic and manual exchange rate updates
- PDF receipt generation
- Email notifications

## Technology Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Google Apps Script
- **Database**: Google Sheets
- **Storage**: Google Drive
- **Hosting**: GitHub Pages / Netlify

## Key Business Rules

✓ All deposits require admin approval
✓ All withdrawals require admin approval
✓ All transfers require admin approval
✓ All exchange offices require admin approval
✓ Auto-generated unique transfer numbers
✓ Real-time exchange rate updates (every 30-60 seconds)
✓ Automatic PDF receipt generation
✓ Email notifications for approvals
